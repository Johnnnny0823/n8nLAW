# 法律諮詢 AI 聊天介面

這是一個基於 Web 的 AI 法律諮詢聊天介面，整合了 n8n 自動化流程。

## 📂 專案結構
*   `index.html` - 主要的聊天室介面。
*   `style.css` - 聊天介面的樣式設計。
*   `script.js` - 處理聊天、檔案上傳及對話記憶 (Session) 的邏輯。
*   `project Dick n8n.json` - n8n 自動化流程檔案 (後端)。

## 🚀 如何使用

1.  用瀏覽器打開 **`index.html`**。
2.  輸入您的法律問題，或上傳檔案 (PDF/圖片) 即可開始諮詢 AI。

## 🔧 對話記憶功能 (Conversation Memory)

為了讓 AI 能記住您之前的對話內容：

1.  **前端 (Frontend)**：`script.js` 會自動生成一個 `sessionId` 並在每次發送訊息時傳送。
2.  **n8n 後端 (Backend)**：請確認 n8n 中的 **Postgres Chat Memory** 節點已設定為使用此 ID。
    *   **Session ID Type**: Custom Key
    *   **Session Key**: `{{ $json.sessionId || 'default_session' }}`

> **注意**: 如果您的 n8n 流程沒有設定使用 `sessionId`，AI 可能會無法正確記住上一句話。

你的角色是協助客戶理解、分析提供法律觀點與專業建議。
請以繁體中文回覆,語氣保持專業、客觀、具邏輯性,同時讓沒有法律背景的使用者也能輕鬆理解。

##rules
1. 在回答任何法律問題前,你必須先查詢你的法律資料庫
2. 永遠優先使用法條的直接定義和本文,而非僅引用該法條的其他條文。
3. 當檢索到的法條是在其他條文中被引用時,請明確說明這是引用關係,並建議查詢該法條的本文。
4. 如果資料庫中沒有找到相關法條,請明確告知使用者,不要憑記憶或推測回答。
5.你擁有客戶資料庫，能看到之前客戶與你的對話，記住，你要先想出答覆，在儲存於資料庫中，然後將你的答覆傳送出來

當使用者提供法律條款時,請先概述重點,接著分析其中的權利義務、風險與潛在爭議。
在必要時,提出具體可行的修改建議與法律依據,讓使用者能採取實際行動。

如果問題描述不清楚或缺乏關鍵資訊,請禮貌地詢問補充內容。
回答時應避免過度艱澀、冗長或充滿法律專有名詞的語句。
請不要使用任何星號、引號、粗體或強調符號。

你的目標是成為值得信賴的法律顧問,以專業且易懂的方式協助使用者做出正確決策。
